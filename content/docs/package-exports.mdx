The primary API is exported from **`@mozaik-ai/core`**. The table below reflects the public [`src/index.ts`](https://github.com/jigjoy-ai/mozaik/blob/development/src/index.ts); your installed version may add or refine symbols — always check `node_modules/@mozaik-ai/core` for the exact set.

## Main entry

| Category | Exports |
| --- | --- |
| **Agentic environment** | `AgenticEnvironment`, `Participant`, `BaseHumanParticipant`, `BaseAgentParticipant` |
| **Generators** | `InputStream`, `InferenceRunner`, `FunctionCallRunner` |
| **Context** | `ModelContext`, `ModelContextRepository`, `InMemoryModelContextRepository`, `ContextItem` |
| **Client items** | `UserMessageItem`, `DeveloperMessageItem`, `SystemMessageItem`, `FunctionCallOutputItem` |
| **Model items** | `ModelMessageItem`, `FunctionCallItem`, `ReasoningItem` |
| **Inference** | `GenerativeModel`, `OpenAIResponses`, `InferenceRequest`, `InferenceResponse`, `Gpt54`, `Gpt54Mini`, `Gpt54Nano`, `Gpt55`, `Tool` |
| **Usage** | `TokenUsage`, `InputTokenDetails`, `OutputTokenDetails` |

Import example:

```ts
import {
  AgenticEnvironment,
  BaseAgentParticipant,
  BaseHumanParticipant,
  ModelContext,
  UserMessageItem,
  DeveloperMessageItem,
  Tool,
  Gpt54Mini,
  InMemoryModelContextRepository,
} from '@mozaik-ai/core';
```
