The primary API is exported from **`@mozaik-ai/core`**. The table below reflects the public [`src/index.ts`](https://github.com/jigjoy-ai/mozaik/blob/development/src/index.ts).

`join`, `leave`, `sendMessage`, `sendEvent`, and `runLoop` are **not** package exports. They come from `defineRuntime()` after `initializeRuntime`.

## Main entry

| Category | Exports |
| --- | --- |
| **Runtime** | `defineRuntime`, `RuntimeState`, `InferenceRunnerConfig` |
| **Participants** | `createAgent`, `createHuman`, `Participant`, `Agent`, `Human` |
| **Situations** | `SituationHandler`, `SituationProcessor`, `SituationSpecification`, `SituationContext` |
| **Loop** | `InterceptionHandler`, `LoopStateExecution`, `LoopTransition`, `ExecutableLoopStateId`, `ExecutableTransition` |
| **Inference** | `InferenceInput`, `InferenceOutput`, `InferenceRunner`, `DefaultInferenceRunner`, `supportedModels` |
| **Events** | `SemanticEvent` |
| **Context** | `ModelContext`, `ModelContextRepository`, `ContextItem` |
| **Client items** | `UserMessageItem`, `DeveloperMessageItem`, `SystemMessageItem`, `FunctionCallOutputItem` |
| **Model items** | `ModelMessageItem`, `FunctionCallItem`, `ReasoningItem` |
| **Tools & MCP** | `Tool`, `McpClient`, `McpServerConfig`, `McpToolSpec`, `McpToolRegistry` |
| **Models** | `Endpoint`, `OpenAIResponses`, `OpenAIChatCompletions`, `AnthropicMessages`, `GeminiGenerateContent`, `StructuredOutputFormat` |
| **Usage** | `TokenUsage`, `InputTokenDetails`, `OutputTokenDetails` |

```ts
import {
  defineRuntime,
  RuntimeState,
  createAgent,
  createHuman,
  SituationSpecification,
  Agent,
  type SituationHandler,
  type SituationContext,
  type InferenceInput,
} from '@mozaik-ai/core';
```
