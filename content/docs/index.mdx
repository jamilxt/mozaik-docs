**Mozaik** is a TypeScript framework for building non-blocking AI agents. It provides a structured **agent loop**, a **lifecycle hook system**, a typed **context model**, and an experimental **multi-agent runtime** — giving you full control over how agents think, act, and collaborate.

## Why Mozaik

- **Agent loop as an FSM** — A finite state machine drives every execution through inference, tool calls, and final messages. Each step is observable and replayable.
- **Lifecycle hooks** — Register `BEFORE_INFERENCE`, `AFTER_FUNCTION_CALL`, `ON_ERROR`, and more on any `AgentRuntime` for telemetry, guardrails, and streaming.
- **Typed context model** — Messages, tool calls, reasoning traces, and outputs are first-class `ContextItem` objects you can append, inspect, and persist.
- **Non-blocking multi-agent runtime** — `AgentSociety` runs agents concurrently on a shared `Context`, removing the sequential bottleneck typical of multi-agent frameworks.
- **Provider-oriented** — `OpenAIResponses` implements the [OpenResponses](https://www.openresponses.org/) spec, so your domain types stay stable across providers.
