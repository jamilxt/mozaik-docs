Mozaik is a TypeScript framework for multi-agent collaboration. Humans, agents, and observers are all `Participant`s of the same runtime. They share typed `RuntimeState`, publish `SemanticEvent`s, and react through situation handlers.

v4 is a new runtime API. You create a session with `defineRuntime`, join participants built by `createHuman` / `createAgent`, and start thinking with `runLoop`. The older environment-and-handler-override style is gone.

## Multi-agent collaboration

Mozaik is built around three attributes:

- **Concurrency** — Agents work alongside one another without blocking. Each `runLoop` is fire-and-forget.
- **Awareness** — Agents understand other participants, events, and their shared `RuntimeState`.
- **Adaptivity** — Agents change behavior based on runtime state and emerging needs, through situation handlers and interception.

Together, these let a team of agents and humans work on the same problem in one session.
