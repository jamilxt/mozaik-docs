## Package

Install the published core library:

```bash
npm install @mozaik-ai/core
```

```bash
yarn add @mozaik-ai/core
```

```bash
pnpm add @mozaik-ai/core
```

The [npm package](https://www.npmjs.com/package/@mozaik-ai/core) is scoped as **`@mozaik-ai/core`**. The latest API surface follows the [Mozaik repository](https://github.com/jigjoy-ai/mozaik) on GitHub; pin a version in production as you normally would.

## Environment

Mozaik picks a provider from the model name you pass to `runLoop` (the `model` field on `InferenceInput`). Each provider SDK reads its credential from the environment. Set the keys for the providers you use:

```bash
# .env
OPENAI_API_KEY=your-openai-key-here
ANTHROPIC_API_KEY=your-anthropic-key-here
GEMINI_API_KEY=your-gemini-key-here
```

DeepSeek models run through the OpenAI-compatible chat-completions endpoint, so they use an OpenAI-style credential and base URL (`OPENAI_API_KEY` / `OPENAI_BASE_URL`) pointed at DeepSeek.

Place these in a `.env` file at your project root (or configure the environment in your host) so server-side code can read them securely. Do not commit secrets.

The bundled model names and how to swap the runner are on [Models](/docs/models).

## TypeScript

Mozaik is written in TypeScript. Make sure your `tsconfig` uses a modern `moduleResolution` (e.g. `"bundler"`, `"node16"`, or `"nodenext"`) so package imports resolve cleanly.
