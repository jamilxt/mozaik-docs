## Package

Install the published core library:

```bash
npm install @mozaik-ai/core
```

```bash
yarn add @mozaik-ai/core
```

```bash
pnpm add @mozaik-ai/core
```

The [npm package](https://www.npmjs.com/package/@mozaik-ai/core) is scoped as **`@mozaik-ai/core`**. The latest API surface follows the [Mozaik repository](https://github.com/jigjoy-ai/mozaik) on GitHub; pin a version in production as you normally would.

## Environment

For OpenAI-backed runs, set your API key:

```bash
# .env
OPENAI_API_KEY=your-openai-key-here
```

Place this in a `.env` file at your project root (or configure the environment in your host) so server-side code can read it securely. Do not commit secrets.

## TypeScript

Mozaik is written in TypeScript. Make sure your `tsconfig` uses a modern `moduleResolution` (e.g. `"bundler"`, `"node16"`, or `"nodenext"`) so package imports resolve cleanly.
